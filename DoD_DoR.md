# Acuerdos de Calidad del Equipo (DoR y DoD)

## 1. Definition of Ready (DoR)
Una historia de usuario se considera lista para ser desarrollada cuando cumple las siguientes condiciones:

- [ ] Tiene un identificador único (ID).
- [ ] Está redactada utilizando el formato estándar de historia de usuario (*Como... quiero... para...*).
- [ ] El valor que aporta al usuario está claramente definido.
- [ ] Tiene una prioridad establecida.
- [ ] Cuenta con criterios de aceptación claros.
- [ ] Se han identificado sus posibles dependencias.
- [ ] Tiene un alcance que puede ser estimado.
- [ ] Puede dividirse en tareas concretas.

## 2. Definition of Done (DoD)
Una historia de usuario se considera terminada cuando cumple las siguientes condiciones:

- [ ] La funcionalidad cumple el requisito aprobado y su alcance definido.
- [ ] Las validaciones de los datos obligatorios funcionan correctamente.
- [ ] Los criterios de aceptación han sido verificados mediante pruebas.
- [ ] Se han revisado los flujos principales y alternativos.
- [ ] No existen errores críticos pendientes.
- [ ] La documentación y la matriz de trazabilidad se encuentran actualizadas.
- [ ] Se cuenta con evidencias de las pruebas realizadas.
