## 1. Objetivo General
Construir y priorizar un backlog de historias de usuario aplicando criterios INVEST, definir los criterios de aceptación usando Gherkin y establecer las condiciones necesarias para que una historia se considere terminada. Asimismo, organizar las historias usando un tablero Scrum/Kanban, planificar una iteración y establecer mecanismos básicos para observar el flujo de trabajo.

## 2. Objetivo de la Iteración (Sprint Goal)
Implementar y validar las funcionalidades principales relacionadas con la gestión de pedidos personalizados de la tienda de ropa.
